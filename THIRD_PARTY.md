# Источники и лицензии

Исходники этой первой версии распространяются по GPL-3.0-or-later, полный текст в LICENSE. Работа с транспортом и форматом измерительных групп разработана с опорой на описание и исходники VAG Blocks.

VAG Blocks — Copyright 2013 Jared Wiltshire, GPL-3.0-or-later.
https://github.com/jazdw/vag-blocks
https://jazdw.net/tp20
В частности, просмотрены tp20.cpp и kwp2000.cpp для последовательностей канала и типов измерительных величин. Java-реализация имеет собственный последовательный обмен, проверку длины и запрет произвольных команд.

Данные Haldex 5 и маршруты диагностики: OpenHaldex-S3 — Copyright (c) 2026 SpringfieldVW.com, MIT. Текст разрешения и отказа от гарантий сохранён в OPENHALDEX-LICENSE.
https://github.com/meatro/OpenHaldex-S3
Из компактного профиля взяты шесть технических определений для конкретного блока 0CQ907554D / 7076; встроена проверка совпадения версии.

Предоставленный пользователем диагностический APK проанализирован локально для совместимости; его исходники, двоичные модули, ресурсы и база в этот проект не включены.

Android SDK и Eclipse Temurin используются только для сборки, в архив проекта не входят. Установленные инструменты находятся отдельно в рабочем каталоге; оригинальные лицензии находятся в их дистрибутивах.
