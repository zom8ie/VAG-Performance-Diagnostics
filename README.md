# Yeti Diagnostics · версия 0.20.0

Персональное Android-приложение для Škoda Yeti, двигателя 1.8 CDAB, коробки DQ250 и Haldex 5. Основной режим — безопасное чтение через Viecar ELM327; очистка ошибок требует отдельного подтверждения.

## Первый запуск

1. Передай `yeti-diagnostics-0.20.0.apk` на Samsung и открой файл для установки.
2. На стоящей машине вставь Viecar в диагностический разъём и включи зажигание.
3. Освободи адаптер: одновременно Viecar обслуживает только одно соединение.
4. Открой **Yeti Diagnostics**, разреши доступ к устройствам поблизости.
5. Нажми плашку **Подключи адаптер** на главном экране и выбери **Viecar**. Если его нет, сначала добавь его через системные настройки Bluetooth.
6. Включи тумблер в шапке. После ответа двигателя откроется меню параметров.
7. Для первого теста открой **Двигатель**. Стандартные и расширенные параметры появятся в одном списке.
8. Вернись в меню и открой DQ250, Haldex 5, ABS/ESP или усилитель руля. Доступные измерения обновляются автоматически, пока открыт экран блока.
9. Нажми **Журнал** на нижней панели. У нужного сеанса нажми значок обмена. Соединение отключается тумблером в шапке.

Кнопка **Тест** под нижней панелью открывает общий каталог параметров с примерами. В разделе двигателя сразу показан весь каталог. Системная кнопка или жест «Назад» из любого раздела возвращают в меню.

Кнопка **Анализ** запускает полный набор проверок OBD, двигателя VAG, DQ250, Haldex 5, ABS/ESP и CAN-шлюза. **Новьё** запускает частичный анализ только новых и пока неподтверждённых функций. После положительного результата проверка убирается из «Новья», но остаётся в полном наборе «Анализ». При временном обрыве связи приложение автоматически делает до шести повторных подключений с увеличивающейся паузой.

Приложение запоминает выбранный адаптер. Действующее соединение внутри приложения можно использовать повторно.

## Что работает в коде

- Значок Android Auto в шапке открывает три сохраняемые страницы по шесть ячеек. Нажатие на «+» открывает выбор блока и параметра. Удержание занятой ячейки открывает подтверждение удаления. После перехода на раскладку 3×2 страницы нужно настроить заново.
- Для просмотра в Android Auto сначала подключи адаптер на телефоне. В редакторе панели есть три страницы по шесть ячеек (3×2). На магнитоле панель рисуется на весь экран: шесть приборов — значение по центру шкалы, единица маленьким шрифтом над ним, подпись под шкалой и зелёная полукруглая шкала с минимумом, максимумом и отметкой текущего значения за сеанс. Тап по любой из двух правых карточек листает страницу вперёд, по любой из двух левых — назад. Двойной тап по любой карточке увеличивает прибор на весь экран, одиночный тап по большому прибору возвращает панель.
- Устройство панели, жесты магнитолы, ограничения и способ повторения в эмуляторе описаны в `AA-FULLSCREEN.md`. Категория NAVIGATION и разрешения поверхности объявлены в обеих сборках; боевой пакет получит полноэкранную панель после релиза и переустановки привычным доверенным способом.
- На экране каждого блока лупа в шапке раскрывает строку поиска по названию параметра. Результаты меняются сразу при вводе текста; точки, тире и другие разделители в запросе не важны. У каждого найденного параметра есть переключатель «Отслеживать», равный по смыслу свайпу.
- Свайп вправо включает параметр, свайп влево выключает его. Жест сначала показывает движение карточки, затем список плавно перестраивается. Выключенные параметры остаются сохранёнными и перемещаются в конец списка, чтобы не мешать наблюдению за активными; служебные строки без рамки остаются в начале. Параметры пропусков зажигания сохраняют порядок цилиндров.

- Подключение к сопряжённому SPP-адаптеру; защищённый, затем обычный SPP при неудаче.
- Последовательная очередь ELM: один запрос — один завершённый ответ. При тайм-ауте сессия прекращается, чтобы запоздалый ответ не стал значением другого датчика.
- Автоматическое определение протокола; для этого Yeti допускается CAN 11-bit, 500 кбит/с. Двигатель адресуется через 7E0/7E8.
- Единый список двигателя: до 41 стандартного параметра, подтверждённых маской поддержки ЭБУ, и расширенные измерительные группы VAG. Отдельно показываются напряжение адаптера, статус Check Engine и коды ошибок двигателя.
- Параметры читаются по очереди: сначала стандартный OBD, затем расширенные группы двигателя. Это сохраняет безопасный последовательный обмен с ЭБУ. Для проверенных групп двигателя используется ожидание 40 мс; при сбое чтение повторяется в новом канале с обычным ожиданием 96 мс. После расширенного канала приложение восстанавливает стандартную длину CAN-кадра перед OBD. Если данных слишком много, выключи ненужные карточки свайпом — это прямо сокращает длительность круга опроса.
- Расширенные группы двигателя читаются экспериментально через KWP2000 / VW TP2.0; DQ250 — через температурную группу 019. Названия неподтверждённых полей отмечены `(?)`. Неизвестный формат остаётся сырыми байтами.
- Для двигателя добавлены группы CDAB/VAG для наддува 114/115, коррекций смеси 032, фаз 091/093, давления топлива 106, пропусков 014–016 и откатов зажигания 020. Фактическая доступность зависит от того, разрешит ли конкретный ЭБУ канал TP2.0.
- DQ250: скорости валов, токи клапанов, моменты и давления сцеплений, положения вилок, температуры, передача, счётчики температурных предупреждений и история температуры масла. Кнопка в разделе читает ошибки коробки.
- ABS/ESP: идентификация, память ошибок и циклическое чтение подтверждённых групп MK60EC1. У MK100 доступны идентификация и ошибки, пока карта измерений не подтверждена.
- CAN-шлюз: чтение списка установленных блоков, если шлюз поддерживает этот запрос.
- Усилитель руля: идентификация блока, чтение ошибок и циклическое обновление момента и угла руля при поддержке соответствующих измерений.
- Карточка блока показывает адрес, номер детали, версию прошивки и аппаратный номер. Прочерк означает, что поле не получено. Чтение памяти ошибок доступно во всех разделах.
- В карточке блока доступны «Кодировки», «Параметрии» и «Ошибки». Результат поясняет, что именно считано; полный набор параметрии не выгружается.
- Нажатие на измеряемый параметр раскрывает краткое объяснение; «Свернуть» возвращает обычный компактный вид карточки.
- Свайп по карточке параметра влево выключает его из циклического опроса, вправо — возвращает в опрос. При первой установке все параметры включены. Выбор хранится локально и сохраняется после обычного обновления приложения с тем же пакетом и подписью.
- При сворачивании выбранный блок продолжает обновляться через службу Bluetooth. Если при этом открыта панель Android Auto, служба опрашивает параметры панели. Выход из блока останавливает его опрос. Кнопка «Отключить» в уведомлении завершает соединение.
- При найденной ошибке открывается отдельное окно с кодами и краткими собственными пояснениями для наиболее частых ошибок. Очистка доступна только после отдельного подтверждения и отправляет одну из двух фиксированных команд: стандартную OBD-команду `04` для двигателя или UDS-команду `14FFFFFF` для выбранного блока. Сначала сохраните журнал: удаление не устраняет причину, а для двигателя также сбрасывает контроль готовности.
- Доступны три оценки мощности в кВт и л.с.: по расходу воздуха, по расходу воздуха с коэффициентом смеси λ и по мгновенному расходу топлива ЭБУ. При отсутствии нужного входного параметра показывается «—» с объяснением источника, а не выдуманное значение. Оценки зависят от режима двигателя и не заменяют стендовые измерения.
- Haldex 5: идентификация UDS и шесть запросов параметров. Поддержаны варианты **0CQ907554D / 7076** и обнаруженный в журнале автомобиля **0AY907554J / 7522**. Для второго варианта значения помечаются как требующие проверки на машине: открытая карта параметров подтверждает поколение и адреса, но не является заводской картой именно этой ревизии.
- Работа соединения в службе Android с уведомлением и кнопкой отключения; кнопка «Обновить список блоков» повторно запрашивает список CAN-шлюза.
- Два режима анализа: полный набор безопасных чтений и короткий набор новых проблемных проверок. Успешные и неуспешные стратегии, ответы D6/D7/D8, тайм-ауты и повторы групп записываются отдельно.
- В конце полного анализа сравниваются паузы 40, 20 и 0 мс на одинаковом наборе стандартных параметров двигателя. В «Новье» это сравнение выполняется только до первого подтверждённого результата. Результаты содержат среднее время круга, пропуски, тайм-ауты и ошибки связи.
- В «Новье» и полном анализе дополнительно сравнивается время ожидания TP2.0: 96, 64 и 40 мс на одинаковой серии расширенных групп двигателя. Более короткое значение признаётся только при полном наборе ответов; результат записывается в журнал анализа.
- Супервизор Bluetooth: при EOF, тайм-ауте или сбросе SPP закрывает старый сокет и автоматически пробует заново защищённый и обычный SPP до шести раз.
- Автоматический локальный дневной журнал; экспорт одного JSONL-файла через системное меню обмена.

## Проверка текущей версии

APK собран и подписан. Протокол, формулы и повторный опрос проверены автоматическими тестами. Проверка этой сборки на Samsung с Viecar и автомобилем ещё предстоит.

Android: минимальная версия 12 (API 31), сборка/target API 36. Запуск на указанном Android 17 и One UI 9 нужно подтвердить на телефоне. Нативных библиотек нет.

Часть полей зависит от версии блока. Неподтверждённые форматы сохраняются в журнале. Для климата и приборной панели список шлюза помогает определить наличие блока.

Профиль DQ500 был выбран пользователем из-за отсутствия DQ250; формулы DQ500 в приложение не перенесены.

Нет адаптаций, кодирования, запуска насоса, исполнительных тестов или произвольной консоли команд. Единственное изменяющее действие — подтверждённая пользователем очистка ошибок выбранного блока. Открытие диагностического сеанса и настройка транспорта нужны для чтения; они не являются изменением кодировки.

## Журналы

- На каждую версию и календарный день создаётся один файл, например `v0.20.0-yeti-20261117.jsonl`.
- Внутри файла поле `run_id` отделяет подключения друг от друга; записи `run_start` и `run_end` обозначают начало и конец запуска.
- Каждая строка — самостоятельная JSON-запись: обмен с адаптером, ошибки и расшифрованные значения. Это формат JSONL — JSON по одной записи в строке.
- При запуске новой версии удаляются журналы, созданные предыдущими версиями; для текущей версии сохраняются до 8 последних календарных дней.
- `utc_ms` — время Unix в миллисекундах; `elapsed_ms` — монотонные часы Android.
- Предел дневного журнала — около 16 МиБ; при достижении запись останавливается с сообщением, а не тихо теряется.
- Экспорт текущего журнала — согласованный снимок одного файла: запись временно блокируется на время копирования.
- VIN, геолокация и MAC-адрес не запрашиваются в журнале; ответы могут содержать идентификаторы блоков. Экспорт передаётся пользователем вручную.
- Запись журнала начинается после подключения к адаптеру. Демонстрационные значения в режиме **Тест** остаются на экране.

## Разработка и повторная сборка

Исходники находятся в `app/src/main/java/ru/yeti/diag`. Интерфейс написан на Java со стандартными элементами Android, без внешних библиотек приложения. Это уменьшает размер APK и инструментария.

- `./test.sh` — проверки протокола и формул без телефона.
- `./build.sh` — сборка и проверка APK в папке `build`. Требуется Gradle 8.13. Можно указать путь через `YETI_GRADLE`. Имя по умолчанию берётся из версии в манифесте, путь тестового APK можно задать через `YETI_APK_OUT`.
- `YETI_BUILD_VARIANT=debug ./build.sh` — отдельная сборка для Desktop Head Unit: у неё пакет `ru.yeti.diag.dhu`, поэтому она устанавливается рядом с основной и принимает тестовый хост. Это не сборка для магнитолы.
- Для локальной проверки вида на экране 800×480 подключи телефон по USB и запусти `desktop-head-unit -c build/dhu/yeti-6_5in.ini -u <серийный номер телефона>`. Отладочная сборка подставляет меняющиеся демонстрационные показания, реальный адаптер не нужен. В окне эмулятора приложение открывается значком в списке всех приложений Android Auto.
- Инструменты на этом Mac размещены в `../../work/toolchain` относительно проекта. Android Studio и эмулятор не установлены.
- Для другого компьютера задай `YETI_JAVA_HOME`, `YETI_SDK`, `YETI_BUILD_TOOLS`. `YETI_SDK` должен содержать каталог `android-36/android.jar`; параметр `YETI_BUILD_TOOLS` — каталог build-tools 36.0.0. У Google этот архив имеет внутреннее имя `android-16`.
- Локальный ключ подписи находится в `../../work/toolchain/signing/yeti-local.p12`. Сохрани его для следующих обновлений этого приложения. Это ключ тестовой установки с известным локальным паролем, не ключ публикации в магазине; в архив исходников он не включён.

### Установка кабелем с этого Mac

Если удобнее USB: подключи телефон, включи **Параметры разработчика → Отладка по USB**, подтверди на телефоне доверие этому Mac. Отладка по USB разрешает компьютеру устанавливать и проверять приложения. Затем `./install.sh` установит APK и откроет его; скрипт работает только при одном подключённом и разрешённом устройстве. Для экранного приложения Android Auto этого недостаточно: оно устанавливается на реальную магнитолу только из доверенного источника, например через внутреннее распространение приложения. Во время разработки телефон по USB не обнаружен, поэтому скрипт установки на устройстве не выполнялся.
