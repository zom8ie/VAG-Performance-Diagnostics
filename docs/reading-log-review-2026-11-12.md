# Чтение параметров: разбор журнала 0.14.0

Проверены все 12 981 строки `v0.14.0-yeti-20261112.jsonl`, включая четыре запуска соединения. Здесь рассматриваются полнота ответов, протоколы и расшифровка. Техническое состояние автомобиля по числам не оценивается.

### Haldex

Все четыре спорных запроса получили по четыре положительных ответа. Это не отсутствие связи.

| DID — идентификатор параметра | Фактический ответ | Почему нет числового результата |
| --- | --- | --- |
| `2BE9` | Два байта, в том числе `11 00` | Карта ожидает один байт; значение второго байта для этой версии не подтверждено |
| `2BE4` | Два байта | Длина подходит, но формула не подтверждена для установленной ревизии |
| `2BE5` | Два нулевых байта | Надёжный масштаб перевода длительности не установлен; нулевой ответ не подтверждает формулу |
| `2BF3` | Два нулевых байта | Карта ожидает один байт; формат данной ревизии не подтверждён |

Сырые ответы сохраняются. Параметры с временным отсутствием данных повторяются через 1, затем 5, затем максимум 30 секунд. Успешное чтение сбрасывает задержку. В полном анализе и прямых проверках «Новьё» ожидание фонового повтора не скрывает запрос.

## Соединение и скорость

- Стандартный OBD после первого полного одиночного ответа использует указание «ожидается один кадр». Это убирает ожидание дополнительных кадров. Для длинных ответов такой режим не включается. Неполный или неожиданный ускоренный ответ отключает оптимизацию до следующей инициализации и запускает обычное чтение.
- После TP2.0 восстанавливаются стандартные параметры ожидания OBD: адаптивное время ответа и его верхняя граница. Раньше оставались настройки другого протокола.
- Перед OBD закрывается действующий канал TP2.0. После OBD открывается новый канал с новой последовательностью пакетов. В старом журнале зафиксировано восемь неудачных первых запросов группы 115 после длительного OBD-опроса; повтор через переоткрытие работал.
- Убрана дополнительная пауза 40 мс между группами TP2.0: транспорт уже соблюдает интервал, согласованный с блоком. Пауза обычного OBD отдельно сравнивается встроенной проверкой; уменьшение этой паузы не применяется по догадке.
- Группы без включённых параметров пропускаются, в том числе при непрерывном опросе ABS/EPS. Когда опрашивать нечего, канал закрывается; список выбранных групп сохраняется, а возобновление открывает свежий канал.
- Ответы, пришедшие вместе со служебным обменом `A3/A1`, теперь остаются в очереди разбора. Проверяется младшая часть номера подтверждения `Bn`. Точные повторы завершённого кадра допустимы, посторонние данные по-прежнему отвергаются.
- При запуске `ATZ` пустой знак готовности ещё не завершает сброс: приложение ждёт ответ запуска в рамках того же тайм-аута. Так строка версии адаптера не попадёт в ответ следующей команды `ATE0`.
- Вероятное ручное отключение адаптера, о котором сообщил пользователь, не используется как доказательство нестабильности приложения.

Процент ускорения не измерен на машине. Локальные проверки подтверждают последовательность команд, полноту ответов, обработку отказов и правильность преобразования байтов. Скорость нового опроса нужно сравнить по следующему журналу.
