# Правила зоны кода: приложение и панель Android Auto

- Чтение безопасно: только разрешённые команды адаптера, никаких адаптаций, кодирования, исполнительных тестов и произвольной консоли команд. Единственное изменяющее действие — очистка ошибок после отдельного подтверждения.
- Разметка и жесты Android Auto воспроизводились сложно: хост фиксирует размеры кнопок и ячеек, двойной тап приходит как изменение масштаба, поверхность может быть объявлена раньше готовности. Перед изменением панели читай `AA-FULLSCREEN.md` и не перекраивай разметку вслепую. Базис — единственный полноэкранный вид 3×2 с единицей над значением; удалённые виды 1–3 и прежняя сетка не возвращаются.
- Изменения панели проверяй нажатиями в Desktop Head Unit 800×480 и снимками; путь снимка и число проверок записывай в раздел «В разработке» `CHANGELOG.md`.
- Боевой пакет `ru.yeti.diag` не переустанавливай и не заменяй; через adb ставится только отладочный `ru.yeti.diag.dhu`.
- Тесты и запись результатов — по `tests/AGENTS.md`.
