# Анализ журналов Yeti · 11 ноября 2026

## Короткий вывод

Журналы подтверждают, что Viecar действительно связывается с автомобилем по Bluetooth Classic SPP и получает данные двигателя. Двигатель отвечает по CAN 11-bit, протокол в ELM указан как `A6`; ответы идут от `7E8`, запросы двигателя — через `7E0`. В трёх длинных сеансах получены реальные OBD-показания, идентификатор Haldex и температура DQ250.

Два коротких сеанса не являются диагностикой автомобиля: адаптер не успел открыть соединение SPP, обмен с ЭБУ отсутствует. Наиболее вероятная причина — Viecar уже был занят другим диагностическим приложением либо Bluetooth-соединение осталось в переходном состоянии.

## Что реально подтверждено

| Область | Наблюдение | Вывод |
|---|---|---|
| Телефон | Samsung SM-S9310, Android 17, API 37 | Целевое устройство соответствует задаче |
| Адаптер | ELM327 v1.5, Classic SPP | Используем Bluetooth, а не BLE |
| Двигатель | `0100` отвечает, поддержано 29 из 41 каталогизированного PID | Базовый OBD-режим рабочий |
| Состояние | Check Engine выключена, счётчик DTC 0 | В этих сеансах стандартный OBD не увидел ошибок двигателя |
| Скорость | 0 км/ч | Машина стояла; дорожные параметры не проверялись |
| DQ250 | Группа TP2.0 `019`: 49 / 50 / 49 °C | Температурная группа отвечает; назначение полей пока помечено как предварительное |
| Haldex | `0AY907554J`, ПО `7522`, маршрут `70F → 779` | Это реальный блок Haldex 5 автомобиля, а не выбранный пользователем профиль DQ500 |

## Значения двигателя из журнала

В первой версии часть значений была показана в физических единицах СИ, неудобных для диагностики автомобиля. Например, обороты были в рад/с, скорость в м/с, угол — в радианах. В версии 0.2.0 вывод изменён:

- обороты — **об/мин**;
- скорость — **км/ч**;
- угол зажигания — **°**;
- давление — **бар**;
- расход топлива — **л/ч**;
- температуры — **°C**;
- напряжение — **В**;
- массовый расход воздуха — **г/с**.

Наблюдавшиеся диапазоны в тестах:

- холостой ход примерно **750–760 об/мин**;
- температура охлаждающей жидкости около **58 °C**, то есть двигатель ещё не вышел на обычную рабочую температуру;
- наружный воздух около **3 °C**, воздух на впуске около **30–31 °C**;
- напряжение ЭБУ и адаптера примерно **13,9–14,2 В** — похоже на нормальную работу генератора на холостом ходу;
- расчётная нагрузка примерно **13–16 %**, абсолютная — **18–21 %**;
- MAF около **2,4 г/с** на холостом ходу;
- лямбда около **1,0**;
- краткосрочная коррекция в последнем сеансе около **0 %**, долгосрочная около **+7,8 %**.

Эти значения не являются заключением о состоянии двигателя: двигатель не был полностью прогрет, автомобиль не двигался, а нагрузочные режимы не записывались. Для анализа смеси нужен отдельный журнал после прогрева и короткая поездка с равномерной нагрузкой.

## Haldex 5

Блок ответил на UDS-идентификацию:

- F187: `0AY907554J`;
- F189: `7522`;
- F191: `0AY907554J`;
- F197: `Haldex4Motion`.

Строка `Haldex4Motion` — название компонента, а не номер поколения. Номер `0AY907554J` и ПО `7522` соответствуют пятому поколению для Yeti 4x4. В журнале также есть положительные ответы на DID `0286`, `2BE6`, `2BE7`, `2BE9`, `028D` и `2BF1`.

В версии 0.2.0 этот вариант распознаётся. Значения выводятся с осторожной пометкой: открытая карта, на которой основаны формулы, подтверждает Gen5 и маршрут, но не является заводской ODX-картой именно для `0AY907554J / 7522`. Поэтому первый реальный тест Haldex нужно сравнить с профессиональным диагностическим ПО.

## Что исправлено по результатам журналов

1. Добавлен разбор коротких положительных ответов `41`, `62` и других, которые Viecar отдаёт без отдельного ISO-TP-заголовка.
2. TP2.0 теперь игнорирует служебный keep-alive `A3`, из-за которого ранее после успешной группы DQ250 появлялась ложная ошибка «неожиданный кадр».
3. В группу DQ250 `019` добавлены понятные предварительные имена: масло коробки (G93), масло сцепления (G509), блок мехатроника (G510). Знак `(?)` оставлен, потому что точный порядок нужно подтвердить на конкретной ревизии блока.
4. Haldex больше не считается неизвестным только потому, что в стороннем приложении нет отдельного профиля DQ250 или показывается DQ500. Это разные блоки и разные транспортные режимы.

## Что пока нельзя утверждать

- Журналы не содержат полного сканирования ABS, Airbag, BCM, климатической установки и других блоков.
- Нулевой счётчик стандартных DTC означает только отсутствие кодов в ответе двигателя OBD в этот момент, а не отсутствие ошибок во всём автомобиле.
- Haldex пока не следует использовать для исполнительных тестов или запуска насоса: приложение остаётся только для чтения.
- Нельзя считать демонстрационные значения на присланных скриншотах показаниями автомобиля; источником истины здесь являются только реальные журналы обмена.

## Практический следующий тест

1. Закрыть другие диагностические приложения и оставить Viecar подключённым только к новому приложению.
2. Включить зажигание, запустить режим двигателя и дождаться прогрева выше 80 °C.
3. Сохранить 2–3 минуты холостого хода.
4. Отдельно записать короткую поездку: ровное движение 40–60 км/ч, затем один плавный разгон.
5. Остановиться и отдельно записать режим DQ250 и Haldex 5.

Такой журнал уже позволит отделить особенности холодного запуска от устойчивых параметров и проверить карту Haldex на реальной машине.
